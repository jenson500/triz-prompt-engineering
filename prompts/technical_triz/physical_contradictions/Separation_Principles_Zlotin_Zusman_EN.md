# Physical Contradiction Resolution Strategies — Zlotin/Zusman Variant (EN)

Source of the strategy/principle assignment: **Zlotin/Zusman** (table "Contradiction Solution Route
— Inventive Principles Used To Tackle This Type of Contradiction", plus the Venn diagram version).

The Classical Contradiction Matrix does not tell users how to solve situations in which different
values of the *same* parameter are required (e.g. the length needs to be long and short, the
material needs to be porous and not porous). Such situations are physical contradictions.

This variant offers **five main strategies**: four associated with separation of the contradictory
requirements, and one involving the transition of the system to something else.

> **Terminology rule:** In English always use exactly these terms: *Separation in Space*,
> *Separation in Time*, *Separation on Condition*, *Separation between the parts and the whole*,
> *Transition to Alternative System* (with the sub-variants *Transition to Sub-System*, *Transition
> to Super-System*, *Transition to Alternative System*, *Transition to Inverse System*).
> Do not mix them with the terms of the Litvin variant (see `Separation_Principles_Litvin_EN.md`) —
> in particular, *Separation on Condition* here is **not** the same category as Litvin's
> *Separation in relation*, and *Separation between the parts and the whole* is **not** Litvin's
> *Separation in system level*.

## 2. Recommended way of using the table

Identify which of the five strategies is possible, by asking:

* "Can the contradictory requirements be separated **in space**?" (Where?)
* "Can they be separated **in time**?" (When?)
* "Can they be separated **on condition**?" (If/under which condition?)
* "Can they be separated **between the parts and the whole**?"
* "Can the system be **transitioned to an alternative system**?"

For each strategy where the answer is yes, the relevant Inventive Principles can be used to help
realise the separation or transition that will solve the contradiction.

**No restriction:** As with the conflict situations represented by boxes in the Matrix, it is always
possible to simply use **all 40 Inventive Principles** as a means of generating ideas for any type
of conflict or contradiction problem. The Matrix and this physical contradiction table offer more
systematic approaches (and thus efficient short-cuts), but they are not compulsory.

## 3. Venn diagram version

Since it is rare for a given contradiction to be relevant in only one of the above categories, a
Venn diagram version of the translation from problem type to recommended Principles is used as an
alternative or complement to the table. The three main strategies **SPACE**, **CONDITION** and
**TIME** form three overlapping circles inside an outer circle:

| Segment | Recommended Inventive Principles |
|---|---|
| SPACE only | 14, 17, 26, 29 |
| TIME only | 9, 10, 18, 21 |
| CONDITION only | 6, 8, 12, 33, 38, 39 |
| SPACE ∩ TIME | 7, 15, 27, 34, 37 |
| SPACE ∩ CONDITION | 1, 28, 30, 31, 40 |
| CONDITION ∩ TIME | 11, 16, 19, 20, 23 |
| SPACE ∩ CONDITION ∩ TIME (centre) | 2, 3, 4, 5, 13, 22, 24, 25, 35 |
| outside all three circles | 32, 36 |

**How to use it:** First determine which of the three main strategies — Space, Time, Condition —
could be applied (using the questions Where? / When? / If?), then start from the corresponding
segment of the diagram. If a given contradiction appears solvable by the Space *and* the Time
strategy, then 7, 15, 27, 34 and 37 are the most probable principles to try. If that does not lead
to a satisfactory result, move on to the neighbouring segments and try the principles found there.

## 4. How to use this file

1. Formulate the challenge as a physical contradiction, including a justification for each of the
   two values of the parameter.
2. Check all five strategies with the questions from section 2; use the Venn diagram (section 3)
   when more than one of Space / Time / Condition applies.
3. Look up the recommended Inventive Principles in `40_Inventive_Principles_EN.md` and derive
   concrete solution ideas from them.
4. Optionally continue the search across all 40 Inventive Principles.
5. Write down the concrete ideas for every abstract solution direction.
